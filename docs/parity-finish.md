# Apollo 持续整改与当前验收

日期：2026-10-19。候选版本：0.1.2。原版基准仍为 Apollo v2.5.2，
`ed9785c87b390c22efece9ea7ec7eeab2d20a042`。旧审计与 0.1.1 整改记录保留，
本文件、`parity/finish-manifest.json` 是本轮对应的证据。

## 已修复

- 权限页同时显示全局及全部环境授权组。授予目标不影响其他组展示；删除按所在行环境校验，
  查询 pending 期间不允许误写全局或其他环境。
- 独立实现可搜索、键盘选择及多选用户控件。消费者创建共享唯一 AppId，查询 Token 不清空创建草稿，
  更换 AppId 清除旧 Token/失败表单快照，键盘选择负责人不会被搜索字符串覆盖。
- 补齐紧凑集群行、横排查询/操作表单、Namespace 选项和同步默认目标/源集群行。
  应用信息默认只读；最后一位管理员不能被移除，显示原版专用 warning。
- 恢复 14 种灰度/权限/锁/语法/删除提示状态，包含创建灰度须知、修改灰度规则后的未发布提示、
  发布成功后无规则提示、编辑/发布分离及紧急发布、合并被主版本草稿阻断等。
- 主版本及灰度锁徽标读取真实 `lock-info`，不再依赖虚构的 NamespaceBO 字段。
  迟到锁/语法/历史回滚响应不会替换新页面、编辑器或历史选择。
- 灰度页显示未被覆盖的主版本配置，并允许创建灰度覆盖；只 POST 到捕获的灰度分支，
  清除原主版本 Item ID，保持父版本不变。删除覆盖后的继承展示按原版规则处理。
  灰度删除也在弹窗前、提交前校验锁，使用原版 Key/Value 确认而非额外输入 ID。
- 历史回滚读取实际选定 Release、当前有效 Release，预览后另行确认；JSON 格式化不丢失
  64 位整数、指数和负零。隐藏 Namespace 保护不会因切到灰度而丢失。
- 按原版授权管理页显示 AccessKey/消费者 Token，去除未经接受的默认脱敏/揭示按钮差异。
  密钥不写 UI 持久化状态，连接密码/cookie 不进入 UI；消费者 RPC 的 Token 仍使用脱敏边界。
- 修复页脚高度/滚动条/左右 gutter、弹窗标题字体与按钮间距、强制删除表格。
  最终遍历发现并修复页脚遮挡侧栏的回归；三种窗口宽度共 15 个入口命中检查通过。

## 严格全量 1:1 门禁仍未通过

**这些修复不等于用户要求的全部页面、全部弹窗/状态已经完成 1:1。**

- 普通管理页仍存在字段列宽/间距、部分标签/说明、表格边界、图标与按钮排列差异；应用设置、
  用户/参数、消费者、导入导出、审计等页面不能标为完全一致。
- 发布/回滚预览、比较/同步第二步、编辑表单和若干条件状态尚未完成全部原版上下文的逐态像素验收。
  部分资源删除确认与原版仍有流程差异。
- 少数提示（管理员、规则更新、无规则发布和紧急确认）的内部像素已匹配，但原版框体在当前桌面场景有 4px 横向偏移；不将其框体标为通过。
- 外部帮助链接在 SDK sandbox 内仍有宿主适配差异，未擅自当作用户已接受的例外。
- 3 个旧删除拒绝声明在 pinned 原版没有调用路径；通用确认模板不是独立页面。台账明确标为
  source-only/模板，不伪造触发，也不把它们说成插件运行失败。

当前逐项清单：`parity/finish-manifest.json`。自包含双栏报告：
`../output/playwright/finish/report.html`。入口、所有声明和已触发状态均由开发侧检查；
未完成项仍归开发侧，不转交用户补做对照。
