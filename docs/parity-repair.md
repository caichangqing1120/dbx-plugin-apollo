## 同时补回的能力

- String 允许空值；Number/Boolean/JSON 独立校验；Boolean 专用选择器，修改时 Key 只读；跨集群新增、部分成功后的重试目标；JSON 格式化、展开编辑、全选目标。
- 发布展示真实已发布值与待发布值；回滚先预览再二次确认，回滚不擅自丢弃草稿；显式撤销恢复发布基线。
- 灰度放回项目侧栏/Namespace 主灰度布局，配置、规则、实例、历史四个页签；全量合并前及最终写入前重查主版本草稿。
- 灰度规则恢复实例选择、手动 IPv4、IP/标签增删与去重、仅标签规则、公共 Namespace 全实例规则、同 AppId 重复限制。关联公共 Namespace 按真实 `parentAppId` 固定当前应用；迟到实例查询不清空输入。
- 用户同页创建/编辑、参数内联修改、应用管理员及默认只读基本信息、独立多环境集群创建、按环境密钥区域、Master 查询后允许/禁止、分资源查询后删除、审计三栏、消费者 Token 查询和两组导入导出表单。
- 发布历史恢复原版静态操作图例和时间线布局，不能把图例误当过滤按钮；10 条分页、隐藏 Namespace 不读取版本值、异常结果可重试。
- Namespace 使用情况重新查询；自有 AppNamespace 即使实例数为零，只要仍有使用记录也必须显式确认。

## 未通过的完整 1:1 门禁

**本轮修复完成不等于全部页面、全部状态已经 1:1。严格门禁仍为 FAIL。**

开发侧逐页查看后仍发现正常页面差异：权限页没有同时展开所有环境的授权分组；用户选择器、部分表单横向排列/宽度、集群行与操作位置、同步默认勾选、若干帮助文字及长页高度仍不同。部分原版专门警告/确认弹窗仍使用通用提示，创建灰度说明等流程尚未全部同构。逐项残余见新台账，不能把它们缩写成“仅少量像素问题”。

密钥默认脱敏、外部链接在受限 sandbox 中复制而非新窗口打开是显式记录的安全/宿主适配差异，不擅自认定用户已经接受这些 1:1 例外。

原版静态页面与受控夹具不是实际 Apollo 部署。本轮未执行真实 Apollo 写入、原生桌面安装/Secret Store/文件保存验收、提交、推送、发布或远端 issue 回写。
