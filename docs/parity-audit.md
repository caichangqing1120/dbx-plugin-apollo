日期：2026-10-19。结论：**FAIL，当前候选版不满足“全部页面/弹窗 1:1 还原”。**

这不是等待用户验证的事项，也不是因为没有真实 Apollo 环境而无法做 UI 对照。

前一份记录中的“功能已补齐”只代表部分路由/接口存在，不能外推成原版交互完整。

- 原版：Apollo v2.5.2，commit `ed9785c87b390c22efece9ea7ec7eeab2d20a042`。本轮从该提交的 GitHub raw 读取公共样式，与本地参考源 SHA-256 相同（`42c9b4ef04537e125ca7f0c57cdebdb8ca41019bd342aa7bcf43be87ee603f0c`）；这项仅验证该文件，不冒充逐文件校验整个归档。
- 实现：独立插件仓 `codex/apollo-admin-plugin`，无初始提交，沿用隔离开发目录。
- 源码内容摘要在 `parity/manifest.json` 的 `nativeSourceSHA256`，不使用不存在的 HEAD 充当版本。
- 页面清单覆盖原版 **24 个管理页面入口**；另外明确列出 DBX 登录适配、SSO 心跳排除项及已计入弹窗的片段。
- 弹窗清单覆盖原版 **31 处声明**，含公共确认模板，以及不同页面中的同名确认；不是 31 种独立业务弹窗。
- 两侧对照宽度均为 **1304px**；参考视口 1304×876，插件真实 SDK 容器内视口 1304×876。
- 真实 Go sidecar + DBX SDK sandbox，原版单独运行在本地参考页，不进入插件交付物。
- 受控数据包含 DEV/UAT、default/extra、发布版本/草稿、灰度分支、密钥和消费者，无生产操作。

- 24 个管理入口均有原版/实现截图。另捕获配置文本/更改历史/实例、灰度和用户/参数编辑等状态。
- 插件第一轮完整遍历输出 51 个页面/弹窗状态；额外捕获回滚、第三方赋权/删除和空值/Boolean 控件状态。
